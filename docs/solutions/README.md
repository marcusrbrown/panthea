# Solutions

Solved problems and practices, organized by category directory:

- `best-practices/`
- `developer-experience/`
- `integration-issues/`
- `logic-errors/`
- `performance-issues/`
- `runtime-errors/`
- `security-issues/`
- `test-failures/`
- `workflow-issues/`

Each doc carries YAML frontmatter: title, date, category, module, problem_type, component, severity, tags. Bug-track docs (defects and failures) add symptoms, root_cause, and resolution_type. Knowledge-track docs (practices and guidance) add applies_when.

New docs come from `ce:compound`; existing ones are kept current with `ce:compound-refresh`.

The category directories are the index.
